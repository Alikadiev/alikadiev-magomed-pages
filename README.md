# Сайт Магомеда Аликадиева — готовая сборка

Просмотр: https://alikadiev.github.io/alikadiev-magomed-pages/

Этот публичный репозиторий содержит только статическую сборку сайта и сценарий публикации GitHub Pages. Исходники находятся отдельно в приватном репозитории владельца.

Файлы site-build.part-01…07 — последовательные части одного tar.gz архива. Workflow объединяет их, проверяет SHA-256, распаковывает и публикует. Части разделены из-за ограничения размера файлов при загрузке через браузер.

Действующий сайт https://alikadiev-magomed.alikadievmr.chatgpt.site/ и его хостинг не изменяются.

Серверная отправка формы в этой статической копии не подключена. Для связи используйте телефон, указанный на сайте.

Изображения предоставлены владельцем сайта; разрешение на повторное использование не предоставляется.
